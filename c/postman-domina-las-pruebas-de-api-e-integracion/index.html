Sobre el curso

"Domina Postman: Impulsa tus habilidades de pruebas API y automatización para acelerar tu camino al éxito!!

Lo que cubre

  • Aprenderás a utilizar POSTMan para realizar peticiones HTTP básicas como GET, POST, PUT y DELETE
  • Aprenderás a trabajar con headers y parámetros en las peticiones
  • Aprenderás a realizar autenticación y autorización en las peticiones
  • Aprenderás a probar y documentar APIs utilizando POSTMan
  • Aprenderás a utilizar variables y variables globales en POSTMan
  • Aprenderás a crear scripts de prueba y automatizar las pruebas
  • Aprenderás a utilizar las funciones avanzadas de POSTMan
  • Aprenderás a trabajar con colecciones de peticiones y documentar API
  • Aprenderás a implementar los conocimientos adquiridos en un proyecto real.
  • Aprenderás a usar la librería Newman para ejecutar desde la terminal tus colecciones
  • Aprenderás a crear mocks para facilitar el trabajo de Testers y Devs
